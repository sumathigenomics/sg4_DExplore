##  Overview
**sg4_DExplore** is an interactive bioinformatics dashboard designed for the rapid exploration, annotation, and functional interpretation of RNA-Seq differential expression data. Developed specifically for researchers working with **DESeq2** outputs, the tool streamlines the transition from statistical tables to biological discovery.

##  Key Features
* **Automated Gene Annotation:** Seamlessly maps Ensembl IDs to official Gene Symbols using the MyGene.info API.
* **Interactive Volcano Plots:** Dynamic filtering using $|log_2 \text{Fold Change}|$ and $p_{adj}$ thresholds with real-time visualization.
* **Expression Heatmaps:** Visualizes sample-specific variance using row-wise Z-score normalization for top differentially expressed genes.
* **Functional Enrichment:** Integrated pathway analysis (KEGG) through the Enrichr API.
* **Publication-Ready Exports:** Download annotated datasets and high-resolution interactive plots.
